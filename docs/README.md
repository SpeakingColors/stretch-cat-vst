# Mockups

Interactive HTML mockups of Stretch Cat. Open any file in a browser, keep `support.js` next to it. Knobs, faders and buttons respond, but nothing makes sound or talks to hardware yet. Fonts load from Google Fonts when online.

- [StretchSampler](mockups/StretchSampler.dc.html)
- [StretchFX](mockups/StretchFX.dc.html)
- [Stretch Cat (Sampler and FX) (interactive, current)](mockup/stretchcat.html): download and open in a browser. Plays real test audio. The older v1 pages are in [mockups](mockups/).
